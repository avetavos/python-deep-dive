## ทัวร์ module สำคัญใน stdlib

Python standard library มีขนาดใหญ่ แต่มี module จำนวนหนึ่งที่ปรากฏในเกือบทุก codebase จริงจัง
บทเรียนนี้จะพาคุณรู้จักห้า module อย่างลงมือปฏิบัติ: `collections`, `itertools`, `datetime`, `json` และ `pathlib`

---

## `collections` — container type พิเศษ

module `collections` ขยาย container built-in ของ Python ด้วยสี่ตัวหลักที่คุณจะใช้ทุกวัน

**`Counter`** นับ hashable object และรองรับ arithmetic บน count

```python
from collections import Counter
c = Counter("aabbbcc")
print(c)           # Counter({'b': 3, 'a': 2, 'c': 2})
print(c.most_common(2))  # [('b', 3), ('a', 2)]
```

**`defaultdict`** ไม่เคย raise `KeyError` — key ที่หายไปจะถูก initialise อัตโนมัติด้วย factory ที่คุณกำหนด

```python
from collections import defaultdict
dd = defaultdict(list)
dd["fruits"].append("apple")   # no KeyError on a fresh key
```

**`namedtuple`** สร้าง record type แบบ lightweight, immutable ที่มี named field — อ่านง่ายกว่า tuple ธรรมดาและไม่มี overhead ต่างจาก tuple ปกติ

```python
from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y)   # 3 4
```

## `itertools` — lazy combinator

`itertools` มี iterator building block ที่ compose ได้ดีและไม่ materialize sequence ทั้งหมดในหน่วยความจำจนกว่าจะถูกขอ

**`chain`** รวม iterable หลายตัวเป็น stream เดียว
**`islice`** ตัด iterator ใดก็ได้อย่าง lazy
**`groupby`** จัดกลุ่ม element ที่มี key เท่ากันติดกัน — input *ต้องถูก sort* ตาม key เดียวกันก่อน

```python
import itertools
list(itertools.chain([1, 2], [3, 4]))          # [1, 2, 3, 4]
list(itertools.islice(range(100), 5))          # [0, 1, 2, 3, 4]
```

print("chained:", merged)

# --- groupby (data must be sorted) ---
data = [("a", 1), ("a", 2), ("b", 3), ("b", 4)]

## `datetime` — date, time และ arithmetic

module `datetime` จัดการ date, time และการคำนวณระหว่างกัน
object `datetime.datetime` เป็น immutable; operation เช่นการบวก `timedelta` จะคืน object ใหม่

## `json` — serialisation และ deserialisation

`json.dumps` แปลง Python object เป็น JSON string; `json.loads` parse กลับ
argument `separators` ช่วยตัด whitespace สำหรับ output แบบ compact

```python
import json
s = json.dumps({"key": "value"}, separators=(",", ":"))
# '{"key":"value"}'
```

## `pathlib` — path ระบบไฟล์แบบ object-oriented

`pathlib.Path` แทน path ระบบไฟล์เป็น object ที่มี method และ property แทนที่การใช้ string ของ `os.path` แบบเก่า

```python
from pathlib import Path

p = Path("/usr/local/lib/python3.12/site-packages/requests/__init__.py")
print(p.suffix)   # .py
print(p.stem)     # __init__
print(p.parts)    # ('/', 'usr', 'local', 'lib', 'python3.12', 'site-packages', 'requests', '__init__.py')

# Building paths with /
project = Path.home() / "projects" / "myapp"
config  = project / "config.toml"
print(config)
```

> `pathlib` จัดการ path ระบบไฟล์ — รัน code นี้ใน local; sandbox ของ browser ไม่มีระบบไฟล์จริง
