## Batteries included

Python มาพร้อมกับปรัชญาที่เรียกว่า **"batteries included"**: standard library มีการ implement พร้อมใช้สำหรับงานที่โปรแกรมส่วนใหญ่ต้องการ — โดยไม่ต้องพึ่ง third-party package
เมื่อติดตั้ง Python คุณจะได้รับ module สำหรับ collections, การจัดการข้อมูล, networking, file I/O, testing, serialisation, concurrency และอีกมากมายโดยอัตโนมัติ

Standard library ครอบคลุมมากกว่า 200 module
ก่อนที่จะใช้ `pip` ให้ตรวจสอบก่อนว่า stdlib module แก้ปัญหาของคุณได้หรือไม่ — จะ import ได้เร็วกว่า, เข้ากันได้กับ Python version ของคุณเสมอ และได้รับความเชื่อถือจากผู้ใช้นับล้าน

## แนวทาง Python tooling สมัยใหม่

โปรเจกต์ Python สำหรับ production มักพึ่งพา tool ชุดเล็กๆ:

- **`venv`** — สร้าง virtual environment แบบ isolated เพื่อไม่ให้ dependency ของโปรเจกต์หนึ่งปนกับอีกโปรเจกต์
- **`pip`** — ติดตั้ง third-party package จาก PyPI ควรใช้หลังจากยืนยันแล้วว่า stdlib ช่วยไม่ได้
- **`pyproject.toml`** — ไฟล์มาตรฐาน PEP-517 สมัยใหม่สำหรับประกาศ package metadata, build backend และการตั้งค่า tool (แทนที่ `setup.py` + `setup.cfg` แบบเก่า)
- **`pytest`** — test runner มาตรฐานโดยพฤตินัยสำหรับโปรเจกต์ Python ซึ่งสร้างบน `unittest` ของ stdlib ด้วย API ที่เป็นมิตรกว่า

คุณจะได้ศึกษา `unittest` และ `pytest` ในบทเรียนถัดไปของ chapter นี้
ตอนนี้ นิสัยสำคัญคือ: **ใช้ stdlib ก่อนเสมอ**

## ลิ้มลองสั้นๆ: stdlib สามโมดูลในการใช้งานจริง

Demo ด้านล่างใช้สามโมดูลที่คุณจะพบบ่อยมาก:

- **`collections.Counter`** — นับ hashable object ในรอบเดียว
- **`itertools.islice`** — ตัด iterator ใดก็ได้อย่าง lazy โดยไม่ต้อง materialize ก่อน
- **`json`** — แปลง Python object เป็น JSON string และแปลงกลับ

Python มาพร้อมกับมากกว่า 200 module ที่ครอบคลุมงานโปรแกรมประจำวันส่วนใหญ่
การใช้ `pip` ก่อนเป็นความผิดพลาด — มันเพิ่มปัญหาด้านการติดตั้ง, versioning และความปลอดภัยที่หลีกเลี่ยงได้ทั้งหมดเมื่อ stdlib เพียงพอ

Module สำคัญที่ควรรู้จักดี:

- **`collections`** — `Counter`, `defaultdict`, `deque`, `namedtuple`, `OrderedDict`
- **`itertools`** — lazy combinator: `chain`, `islice`, `groupby`, `product`, `combinations`
- **`functools`** — `lru_cache`, `partial`, `reduce`, `wraps`
- **`pathlib`** — การจัดการ path ระบบไฟล์แบบ object-oriented
- **`json`** — JSON serialisation/deserialisation ที่รวดเร็ว
- **`datetime`** — date, time, timedelta และรองรับ timezone
- **`re`** — regular-expression engine ครบรูปแบบ
- **`unittest`** — framework การทดสอบ built-in (และเป็นพื้นฐานที่ pytest สร้างต่อยอด)
</Callout>
