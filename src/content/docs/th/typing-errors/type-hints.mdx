## Type hints คืออะไร

**Type hint** คือ annotation ที่แนบไปกับตัวแปร, พารามิเตอร์ หรือค่าที่คืนออกมา เพื่อประกาศว่าควรเป็นประเภทใด
Python เก็บ annotation เหล่านี้ไว้ใน `__annotations__` แต่ไม่เคยนำไปใช้ตอน runtime — เป็นเพียง metadata สำหรับ static analysis tool และผู้อ่านโค้ด

```python
x: int = 10
name: str = "Alice"
```

`: int` และ `: str` ไม่มีผลต่อการรันโค้ดเลย มีไว้เพื่อสื่อสาร intent เท่านั้น

## Annotate signature ของฟังก์ชัน

สถานที่ที่มีประโยชน์ที่สุดสำหรับ type hints คือ function signature — ช่วยบอก contract ของทุก callable

```python
def add(a: int, b: int) -> int:
    return a + b

def repeat(text: str, times: int = 1) -> str:
    return text * times
```

`-> int` annotate ประเภทที่คืน ส่วน default value อยู่หลัง type annotation: `times: int = 1`

## Built-in generic types

Python 3.9+ ให้ใช้ collection type โดยตรงเป็น generic ได้เลย ไม่ต้อง import

```python
scores: list[int] = [95, 87, 92]
mapping: dict[str, int] = {"a": 1, "b": 2}
pair: tuple[str, int] = ("Alice", 30)
unique: set[str] = {"red", "green", "blue"}
```

ก่อน Python 3.9 ต้องเขียน `List[int]`, `Dict[str, int]` จาก `typing` แนะนำให้ใช้ lowercase built-in form ใน Python 3.9+

## Optional — ค่าที่อาจเป็น None

`Optional[T]` หมายความว่าค่าเป็น `T` หรือ `None` ก็ได้ ย่อมาจาก `Union[T, None]`

```python
from typing import Optional

def find_user(user_id: int) -> Optional[str]:
    users = {1: "Alice", 2: "Bob"}
    return users.get(user_id)   # คืน str หรือ None
```

ใน Python 3.10+ เขียนเป็น `str | None` ได้เลย:

```python
def find_user(user_id: int) -> str | None:
    users = {1: "Alice", 2: "Bob"}
    return users.get(user_id)
```

ทั้งสองรูปแบบเทียบเท่ากัน แนะนำ `X | None` ใน Python สมัยใหม่

## Union — หนึ่งในหลายประเภท

`Union[X, Y]` หมายถึงค่าอาจเป็น `X` หรือ `Y` ก็ได้ ใน Python 3.10+ ใช้ operator `|` ได้โดยตรง

```python
from typing import Union

def process(value: Union[int, str]) -> str:
    return str(value)

# Python 3.10+ shorthand:
def process_modern(value: int | str) -> str:
    return str(value)
```

## Type aliases

Type alias ตั้งชื่อให้กับ annotation ที่ซับซ้อน ทำให้ signature อ่านง่ายขึ้น

```python
Vector = list[float]
UserId = int
UserMap = dict[UserId, str]

def scale(v: Vector, factor: float) -> Vector:
    return [x * factor for x in v]
```

Python 3.12+ มี `type` statement:

```python
type Vector = list[float]   # Python 3.12+
```

## Type parameter โดยไม่ต้องใช้ `TypeVar` (Python 3.12+)

PEP 695 ให้ syntax สำหรับ generics โดยเฉพาะ: ประกาศ type parameter ในวงเล็บเหลี่ยมต่อท้ายชื่อได้เลย
ไม่ต้อง import `TypeVar` ไม่ต้องมีตัวแปรระดับ module

```python
def first[T](items: list[T]) -> T:
    return items[0]

class Box[T]:
    def __init__(self, value: T) -> None:
        self.value = value

type Pair[T] = tuple[T, T]     # generic alias
```

รูปแบบเดิมยังใช้ได้ และเป็นสิ่งที่คุณจะเห็นใน code ที่ target 3.11 หรือเก่ากว่า:

```python
from typing import TypeVar

T = TypeVar("T")

def first(items: list[T]) -> T:
    return items[0]
```

## Annotation ถูก evaluate แบบ lazy (Python 3.14)

ก่อน 3.14 annotation ถูก evaluate ทันทีที่ statement `def` หรือ `class` ทำงาน ชื่อที่ยังไม่มีตัวตนจึงต้องใส่ quote
และ `from __future__ import annotations` คือทางออกที่ใช้กันทั่วไป PEP 649 เปลี่ยนเรื่องนี้: annotation ถูกเก็บเป็น
function ที่จะทำงานเมื่อมีคนขอเท่านั้น forward reference จึงใช้ได้เลย

```python
class Node:
    def link(self, other: Node) -> Node:   # Node ยังไม่ถูกนิยาม — แต่ไม่มีปัญหา
        self.other = other
        return self
```

เวลาต้องอ่าน annotation ตอน runtime ให้ใช้ `annotationlib` แทนการแตะ `__annotations__` ตรง ๆ:

```python
from annotationlib import Format, get_annotations

get_annotations(Node.link, format=Format.VALUE)       # object ที่ resolve แล้ว
get_annotations(Node.link, format=Format.STRING)      # ข้อความจาก source
get_annotations(Node.link, format=Format.FORWARDREF)  # ForwardRef ตรงที่ resolve ไม่ได้
```

## เครื่องมือ typing สมัยใหม่ที่เหลือ

| ฟีเจอร์ | เวอร์ชัน | ทำอะไร |
|---|---|---|
| `@override` | 3.12 | checker ตรวจว่า method นั้น override method ของ base จริง |
| `TypeVar("T", default=int)` | 3.13 | ค่า default ของ type parameter ที่ไม่ได้ระบุ |
| `typing.ReadOnly` | 3.13 | ทำเครื่องหมายว่า key ของ `TypedDict` เป็น read-only |
| `typing.TypeIs` | 3.13 | predicate สำหรับ narrowing ที่ narrow ฝั่ง negative ด้วย ต่างจาก `TypeGuard` |
| `@warnings.deprecated` | 3.13 | เครื่องหมาย deprecation ตัวเดียวที่ทั้ง checker และ runtime เข้าใจ |

```python
from typing import ReadOnly, TypeIs, TypedDict, override

class User(TypedDict):
    id: ReadOnly[int]
    name: str

def is_str_list(values: list[object]) -> TypeIs[list[str]]:
    return all(isinstance(v, str) for v in values)

class Base:
    def run(self) -> None: ...

class Child(Base):
    @override
    def run(self) -> None: ...
```

from typing import Optional, Union

# --- variable annotations ---
x: int = 10
name: str = "Alice"
scores: list[int] = [95, 87, 92]
mapping: dict[str, int] = {"a": 1, "b": 2}

# --- function signatures ---
def add(a: int, b: int) -> int:
    return a + b

def repeat(text: str, times: int = 1) -> str:
    return text * times

# --- Optional / X | None ---
def find_user(user_id: int) -> Optional[str]:
    users = {1: "Alice", 2: "Bob"}
    return users.get(user_id)

# --- Union / | ---
def process(value: Union[int, str]) -> str:
    return str(value)

# --- type alias ---
Vector = list[float]

def scale(v: Vector, factor: float) -> Vector:
    return [x * factor for x in v]

# --- run it ---
print(add(3, 4))
print(repeat("Hi", 3))
print(find_user(1))
print(find_user(99))
print(process(42))
print(process("hello"))
print(scale([1.0, 2.0, 3.0], 2.5))

# hints do NOT restrict runtime behaviour
print(add("oops", " still works"))  # Python does not enforce at runtime
`.trim();
