## A guided tour of essential stdlib modules

The Python standard library is large, but a handful of modules appear in almost every serious codebase.
This lesson gives you a runnable introduction to five of them: `collections`, `itertools`, `datetime`, `json`, and `pathlib`.

---

## `collections` — specialised container types

The `collections` module extends Python's built-in containers with four workhorses you will use daily.

**`Counter`** counts hashable objects and supports arithmetic on counts.

```python
from collections import Counter
c = Counter("aabbbcc")
print(c)           # Counter({'b': 3, 'a': 2, 'c': 2})
print(c.most_common(2))  # [('b', 3), ('a', 2)]
```

**`defaultdict`** never raises `KeyError` — missing keys are auto-initialised using a factory you supply.

```python
from collections import defaultdict
dd = defaultdict(list)
dd["fruits"].append("apple")   # no KeyError on a fresh key
```

**`namedtuple`** creates lightweight, immutable record types with named fields — more readable than plain tuples and zero overhead versus a regular tuple.

```python
from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y)   # 3 4
```

## `itertools` — lazy combinators

`itertools` provides iterator-building blocks that compose well and never materialise the full sequence into memory until you ask.

**`chain`** flattens multiple iterables into one stream.
**`islice`** lazily slices any iterator.
**`groupby`** groups consecutive equal-key elements — the input *must be sorted* by the same key first.

```python
import itertools
list(itertools.chain([1, 2], [3, 4]))          # [1, 2, 3, 4]
list(itertools.islice(range(100), 5))          # [0, 1, 2, 3, 4]
```

## `datetime` — dates, times, and arithmetic

The `datetime` module handles dates, times, and the arithmetic between them.
`datetime.datetime` objects are immutable; operations like adding a `timedelta` return a new object.

The demo below uses a **fixed date** so the output is always deterministic — a good habit when writing examples or tests.

---

## `json` — serialisation and deserialisation

`json.dumps` converts a Python object to a JSON string; `json.loads` parses it back.
The `separators` argument lets you strip whitespace for compact output.

```python
import json
s = json.dumps({"key": "value"}, separators=(",", ":"))
# '{"key":"value"}'
```

## `pathlib` — object-oriented filesystem paths

`pathlib.Path` represents filesystem paths as objects with methods and properties, replacing the older `os.path` string-based approach.

```python
from pathlib import Path

p = Path("/usr/local/lib/python3.14/site-packages/requests/__init__.py")
print(p.suffix)   # .py
print(p.stem)     # __init__
print(p.parts)    # ('/', 'usr', 'local', 'lib', 'python3.14', 'site-packages', 'requests', '__init__.py')

# Building paths with /
project = Path.home() / "projects" / "myapp"
config  = project / "config.toml"
print(config)
```

> `pathlib` manipulates filesystem paths — run this locally; the browser sandbox has no real filesystem.

## What arrived, and what left

The standard library moves in both directions. Python 3.13 removed 19 long-deprecated modules (PEP 594) —
`cgi`, `telnetlib`, `crypt`, `imghdr`, `nntplib`, `pipes`, `uu` and friends — plus `lib2to3`. Code importing
any of them needs a third-party replacement or a rewrite.

Worth knowing on the other side of the ledger:

| Addition | Version | Why you care |
|---|---|---|
| `itertools.batched(it, n)` | 3.12 | Fixed-size chunks without a manual loop |
| `pathlib.Path.walk()` | 3.12 | `os.walk` that yields `Path` objects |
| `copy.replace(obj, **changes)` | 3.13 | Generic `dataclasses.replace`, via `__replace__` |
| `dbm.sqlite3` | 3.13 | SQLite is now the default `dbm` backend |
| `glob.translate()` | 3.13 | Shell wildcard to regular expression |
| `compression.zstd` | 3.14 | Zstandard, also wired into `tarfile`, `zipfile`, `shutil` |
| `pathlib.Path.copy()` and `.move()` | 3.14 | Copy and move without reaching for `shutil` |
| `heapq.heapify_max()` and friends | 3.14 | Max-heaps without negating every value |
| `functools.Placeholder` | 3.14 | Skip positional arguments when building a `partial` |
| `Decimal.from_number()` | 3.14 | Exact construction from an `int` or `float` |
